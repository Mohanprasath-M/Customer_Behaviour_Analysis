# Customer_Behaviour_Analysis
Data_Analytics_project Showcasing Customer Behaviour Analysis using Python,Sql,and,Power BI# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using a retail customer dataset containing **3,900 purchase records and 18 columns**.

The main objective is to understand customer spending patterns, product preferences, discounts, customer loyalty, subscription behavior, and demographic trends.

The analysis helps answer the business question:

> **How can the company leverage consumer shopping data to identify trends, improve customer engagement, and optimize marketing and product strategies?**

---

## 🎯 Project Objectives

* Analyze customer purchasing behavior.
* Identify high-value customer segments.
* Compare spending between different customer groups.
* Analyze the impact of discounts on purchases.
* Identify popular products and categories.
* Analyze subscription behavior.
* Understand customer loyalty based on previous purchases.
* Analyze revenue contribution across age groups.
* Create meaningful business insights for decision-making.

---

## 📊 Dataset

The dataset contains **3,900 rows and 18 columns**.

### Main Features

* Customer demographics

  * Age
  * Gender
  * Location
  * Subscription Status

* Purchase details

  * Item Purchased
  * Category
  * Purchase Amount
  * Season
  * Size
  * Color

* Shopping behavior

  * Discount Applied
  * Promo Code Used
  * Previous Purchases
  * Frequency of Purchases
  * Review Rating
  * Shipping Type

There are **37 missing values in the Review Rating column**.

## 🗄️ SQL Analysis

The MySQL analysis contains **10 business queries** covering:

1. Revenue generated by gender.
2. Customers using discounts who spent above average.
3. Top products based on average review rating.
4. Standard vs. Express shipping spending.
5. Subscriber vs. non-subscriber spending.
6. Products with the highest discount usage.
7. New, Returning, and Loyal customer segmentation.
8. Top 3 products within each category.
9. Repeat buyers and subscription status.
10. Revenue contribution by age group.

The SQL queries are stored in:

```text
customer_shopping_behavior_mysql_queries.sql
```

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
cd Customer-Shopping-Behavior-Analysis
```

### 2. Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### 3. Run Python Analysis

Open the Python file in Jupyter Notebook, Google Colab, or VS Code and execute the preprocessing and analysis code.

### 4. Import Data into MySQL

Create a MySQL database and import the cleaned customer dataset.

Example:

```sql
CREATE DATABASE customer_behavior;

USE customer_behavior;
```

Then create/import the `customer` table.

### 5. Run SQL Queries

Open:

```text
customer_shopping_behavior_mysql_queries.sql
```

in MySQL Workbench and execute the queries.

### 6. Build Power BI Dashboard

Connect Power BI to the cleaned dataset or MySQL database and create the required dashboard visuals.
